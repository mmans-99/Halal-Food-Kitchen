📁 Upload recipes from file (TXT, MD, CSV, JSON, PDF)

Upload one or more files. The parser finds all recipes, checks each for halal compliance, and imports the valid ones to your offline database.

Accepted formats:
• TXT / MD — one recipe per block, with Ingredients and Method headings. Separate recipes with # Title, ---, or a blank line followed by a short capitalised line.
• CSV — one recipe per line: Title;meal;cuisine;time;appliance;tags;cal;P;C;F;ingredients;steps
  meal: b/l/d/s/t   appliance: a/s/o/m/n   tags: hp v V g
• JSON — array of objects with fields n,m,c,t,me,tg,cal,p,car,f,i,s (ingredients array, steps array).
• PDF — text-based PDFs only. Scanned/image-only PDFs are not supported (would need OCR). Needs internet on the first upload to fetch pdf.js.

100% halal: no pork, bacon, lard, alcohol, wine or gelatine. Browsing, pantry search, macros and meal planning work fully offline.

Getting a Free Gemini API Key

  1. Visit aistudio.google.com
  2. Sign in with your Google account
  3. Click "Get API key" → "Create API key"
  4. Copy the key (starts with AIzaSy...) into the settings box
⚠️ Never hardcode keys in a public repo. This app keeps it only in your browser storage.
