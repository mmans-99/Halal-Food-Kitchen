# 🍲 Halal Kitchen

A mobile-first, offline-capable cooking web app built for quick halal meal planning, smart pantry matching, and precise macro/calorie tracking.

## Features
- **Strict Halal Guardrails:** No pork, bacon, lard, alcohol, or gelatine.
- **Smart Pantry Matching:** Type ingredients to instantly filter recipes you can make right now.
- **Offline First:** Fully cached via a Service Worker so it works without an internet connection.
- **Weekly Meal Planner:** Generates multi-day menus and compiles a clean shopping list.
- **Gemini AI Integration:** Optional AI recipe generator that safely sanitizes and saves custom recipes locally for future offline use.

## Hosting on GitHub Pages
1. Push `index.html`, `manifest.webmanifest`, `sw.js`, and icon images to your repository root.
2. Go to **Settings > Pages** and set the deployment branch to `main`.
